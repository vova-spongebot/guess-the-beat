# Угадай исполнителя

[English](README.md) | [Русский](README.ru.md)

Музыкальная викторина в браузере. Играет 30-секундный фрагмент известной композиции, нужно выбрать исполнителя из четырёх вариантов. Играть можно одному, вдвоём на одном устройстве или вдвоём по сети.

Весь проект — один файл `index.html`, сервер не нужен.

## Как играть

1. Выберите разделы: **Поп**, **Рок**, **Хип-хоп**, **Клубная электроника**. Можно включить любую комбинацию, треки из выбранных разделов идут вперемешку.
2. Стрелками `<` `>` задайте число раундов (от 1 до 50, по умолчанию 10).
3. Нажмите **1 ИГРОК** или **2 ИГРОКА**.
4. Слушайте фрагмент и выберите исполнителя кнопкой или клавишами `1`–`4`.

## Очки

- За верный ответ даётся до 1000 очков. Пока вы думаете, они убывают, за 20 секунд остаётся 100. Чем быстрее ответ, тем больше очков.
- За неверный ответ или если время вышло — 0 очков.
- **«Убрать 2 лишних»** убирает два неверных варианта, но вдвое уменьшает очки за этот вопрос.

## Игра вдвоём

- На одном устройстве игроки отвечают по очереди.
- Кнопка **«Закончить»** завершает игру досрочно.
- В конце показываются итоговая таблица (место, очки, число верных ответов) и таблица по раундам.

## Игра по сети

1. Оба игрока открывают `index.html` (лучше выложить игру на GitHub Pages и дать ссылку).
2. Первый игрок нажимает **«СОЗДАТЬ КОМНАТУ»** и называет второму 5-значный код.
3. Второй вводит код и нажимает **«ВОЙТИ»**.

Первый игрок ведёт игру, второй видит то же самое и отвечает на своём устройстве в свой ход. Связь идёт напрямую между браузерами через [PeerJS](https://peerjs.com/), поэтому нужен интернет. В строгих корпоративных сетях соединение может не установиться.

## Откуда берутся треки

- **Last.fm** — список самых популярных треков по тегам жанра (например, `house`, `rock`, `hip-hop`).
- **Apple Music (iTunes Search API)** — 30-секундные превью и проверка жанра, чтобы трек не попал не в тот раздел.

Каждый трек выпадает не больше одного раза за сессию.

## Ограничения

- Last.fm не сообщает, был ли трек в чартах. «Известность» определяется по популярности трека в теге, поэтому это приближение.
- Жанры у Apple Music грубые (чаще всего просто Electronic или Dance), поэтому в электронике иногда попадаются смежные стили.
- Если у Apple нет превью для трека, он пропускается.
- Если Last.fm недоступен, игра ищет треки через Apple Music, но подбор хитов при этом хуже.

## Свой ключ Last.fm

В коде (`index.html`, константа `LASTFM_KEY`) вшит ключ Last.fm API. Он виден всем, кто открывает файл. Если выкладываете игру публично, создайте свой бесплатный ключ на <https://www.last.fm/api/account/create> и замените значение.
